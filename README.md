# Oasis 4-Week Data Analytics & Machine Learning Project

## Overview
This repository contains a series of weekly projects focused on data analytics and machine learning, covering customer segmentation, sentiment analysis, data cleaning, fraud detection, house price prediction, wine quality prediction, and more. Each week explores different datasets and techniques, providing hands-on experience with real-world data science problems.

## Week 1: Customer Segmentation
- **Files:** `customer_segmentation.ipynb`, `ifood_df.csv`, `retail_sales_dataset.csv`
- **Goal:** Segment customers based on purchasing behavior and demographics to enable targeted marketing.
- **Key Activities:** Data preprocessing, clustering, analysis of customer segments.

## Week 2: Sentiment Analysis & Data Cleaning
- **Sentiment Analysis:**
  - **Files:** `PlayStore.ipynb`, `Twitter.ipynb`, `apps.csv`, `user_reviews.csv`
  - **Goal:** Analyze user sentiment from Google Play Store and Twitter data.
  - **Key Activities:** Text cleaning, sentiment classification, visualization.
- **Data Cleaning:**
  - **Files:** `new_york_city_Airbnb.ipynb`, `youtube_video_stat.ipynb`, `cleaned_CA_youtube.csv`, `cleaned_new_york_dataset.csv`
  - **Goal:** Clean and explore datasets for Airbnb and YouTube video statistics.
  - **Key Activities:** Handling missing data, duplicates, outlier detection, feature engineering.

## Week 3: Predictive Modeling
- **Fraud Detection:**
  - **Files:** `fraud_detection.ipynb`, `creditcard.csv`
  - **Goal:** Detect fraudulent transactions using machine learning.
  - **Key Activities:** Imbalanced data handling, model training, evaluation.
- **House Price Prediction:**
  - **Files:** `house_price_predicion.ipynb`, `Housing.csv.xls`
  - **Goal:** Predict house prices using regression models.
  - **Key Activities:** Feature selection, model training, evaluation, visualization.
- **Wine Quality Prediction:**
  - **Files:** `wine_quality_prediction.ipynb`, `winequality-red.csv`
  - **Goal:** Predict wine quality based on physicochemical properties.
  - **Key Activities:** Classification, feature analysis, model comparison.

## Week 4: Advanced Data Analytics
- **Google Play Store Data Analysis:**
  - **Files:** `PlayStore.ipynb`, `apps.csv`, `user_reviews.csv`
  - **Goal:** Explore app trends, user behavior, and performance on Google Play Store.
  - **Key Activities:** Data cleaning, category analysis, sentiment visualization.
- **Autocomplete & Autocorrect Data Analytics:**
  - **Files:** `autocomplete_and_autocorrect_data_analysis.ipynb`
  - **Goal:** Evaluate and improve autocomplete and autocorrect algorithms.
  - **Key Activities:** Data-driven modeling, error analysis, performance evaluation.

## How to Use
1. Open the relevant Jupyter notebook for each week in VS Code or Jupyter Lab.
2. Follow the code and markdown cells for step-by-step analysis and results.
3. Datasets are included in the respective folders for each week.

## Requirements
- Python 3.x
- Jupyter Notebook or VS Code
- Common libraries: pandas, numpy, matplotlib, seaborn, scikit-learn, imbalanced-learn, kagglehub
